# horse-solver
一个纯python实现的网络小游戏“小马数独”(找“牛”小游戏)解题器

该游戏的基础规则为：

> 1. 每种颜色1匹小马
> 2. 每行每列均有且仅有1匹小马
> 3. 小马不能相邻（周围9宫格不能有其他小马）

## 1. 功能
- 自动逻辑推导：实现行列唯一、颜色唯一、九宫格互斥等确定性单步逻辑自动判断。
- 高阶互斥：包含了颜色锁定（如果某行/列剩余可能均为同一种颜色，则排除该颜色在其他位置的可能），以及隐藏子集等高阶判定。
- 假设推演 (深度搜索)：当确定性逻辑卡住时，提供手动假设推演功能，包括手动分支假设和回退。
- 状态回溯与快照 (Undo)：支持时光倒流，随时撤销错误的分支假设，并且推演失败会自动将死路格子画叉。
- 图像识别导入：支持上传游戏截图（含网格），自动裁剪背景UI，通过众数采样和色彩聚类提取游戏盘面颜色布局。
- 丰富的可视化UI：使用CSS Grid渲染带颜色的棋盘，有马(🐎)、推演假设马(🦄)和叉(❌)的视觉呈现。
- 推演日志：包含步骤记录和不同级别颜色高亮的推导日志。
## 2. 使用方法（本地运行）
下载完整项目目录，解压进入目录

安装依赖：  
`pip install -r requirements.txt`

运行应用：  
`streamlit run solver.py`  

在浏览器中使用，enjoy


## 3. 高阶使用 Tips 

### 📸 导入棋盘的正确姿势

* **如何粘贴图片最快？**
使用系统的截图快捷键（Win: `Win+Shift+S`，Mac: `Cmd+Shift+4`）截取带有网格的盘面区域。然后在网页左侧找到绿色的 **“📋 点击此处粘贴截图”** 按钮，**用鼠标左键点击一下该按钮**。
* **图像识别不准怎么办？**
引擎已使用了机器学习聚类算法**（K-Means/凝聚层次聚类），能自动克服噪点。但前提是：在解析图片前，**请务必确认“棋盘网格大小”的数字输入正确**（比如 10x10 的盘面必须填 10）。

### 🧠 深度推演引擎使用技巧

* **“单点定点假设” vs “多层深度推演”：**
* 如果你自己对盘面有直觉，建议使用左下角的 **“🔮 手动假设 放 🦄”**，这叫“定点狙击”，你指哪它推哪。
* 如果你毫无头绪，直接点击 **“🤖 开启多层深度推演 (全自动递归)”**。它会接管大脑，穷举所有最少分支的色块。如果发现必死分支，它会自动利用**反证法**退栈并在盘面上画上 `❌`（排雷）。


* **角标颜色的含义：**
* **没有角标**的 🐎 或 ❌ 代表**绝对客观真理**（第 0 层）。
* **白字+同色底**的 🦄 代表你处于的假设层级。
* **彩字+白底**的 ❌ 代表在某层假设下排除了错误选项。如果你看到一个角标写着红色的 `1`，代表这是在第一层假设引发的关联动作。

慎用，会丧失全部游戏乐趣。
